# HistoricalRunApp

מרכז לאפליקציות HTML עצמאיות למסלולי ריצה וטיול היסטוריים.

## אינדקס
`index.html` מציג את כל האפליקציות הזמינות.

## קישור ישיר להורדה
כל אפליקציה מקבלת מזהה `run`.

כרגע:
- `run=1` — שער הגיא / פארק קנדה / נחל יתלה

לאחר הפעלת GitHub Pages:
`https://historicalrunning.github.io/HistoricalRunApp/?run=1`

הדף מנסה להפעיל הורדה אוטומטית. אם הדפדפן חוסם הורדה ללא פעולת משתמש, יוצג כפתור הורדה ידני.
